# Proyecto Bash

## Instrucciones:
1. Crear una variable de ambiente llamada FILENAME:
```bash
export FILENAME="nombre"
```
2. Correr el archivo script.sh:
```bash
./script
```
o
```bash
bash script.sh
```

3. Para matar el proceso background correr el script con el parametro -d:
```bash
./script -d
```
o
```bash
bash script.sh -d
```
